# 🇮🇳 BharatYatra

### Discover India. Experience India. Travel India.

**BharatYatra** is a digital travel platform designed to help people discover the diverse beauty, culture, heritage, food, traditions, and experiences of India — all in one place.

From the Himalayas to the beaches of Kerala, from historic forts to spiritual destinations, BharatYatra aims to make exploring India **simple, informative, personalized, and accessible**.

---

## 🌏 Vision

> **To build a trusted digital gateway for discovering and experiencing India.**

India is more than a collection of tourist destinations. Every state, city, village, monument, festival, cuisine, and tradition tells a unique story.

BharatYatra aims to connect travelers with those stories while helping them plan meaningful journeys across the country.

---

## ✨ Key Features

* 🗺️ **Explore India** — Discover destinations across states and union territories.
* 🏛️ **Heritage & Culture** — Explore monuments, historical places, traditions, and local culture.
* 🍛 **Indian Food** — Discover regional cuisines and local food experiences.
* 🛕 **Spiritual Tourism** — Explore temples, mosques, churches, monasteries, gurudwaras, and other spiritual destinations.
* 🏔️ **Nature & Adventure** — Find mountains, beaches, waterfalls, wildlife, trekking destinations, and adventure activities.
* 🗓️ **Festivals & Events** — Discover festivals, fairs, cultural events, and celebrations across India.
* 📍 **Travel Guides** — Get useful information for destinations and cities.
* 🧭 **Trip Planning** — Plan journeys based on interests, destination, duration, and budget.
* 💡 **Travel Recommendations** — Discover places and experiences based on traveler preferences.
* 📸 **Visual Discovery** — Explore destinations through photos and visual stories.
* 🔎 **Search** — Quickly find destinations, attractions, food, experiences, and travel information.

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/your-username/bharatyatra.git
```

### 2. Navigate to the project

```bash
cd bharatyatra
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure environment variables

Create a `.env` file:

```env
NEXT_PUBLIC_API_URL=
NEXT_PUBLIC_MAP_API_KEY=
DATABASE_URL=
```

Add the required values according to your development environment.

### 5. Start the development server

```bash
npm run dev
```

Open the application in your browser at:

```text
http://localhost:3000
```

## Deploying to Netlify

1. Push this repo and create a new Netlify site from it (settings are picked up from `netlify.toml`).
   - Build command: `npm run build`
   - Publish directory: `dist`
   - Server output: `.netlify/functions-internal` (generated automatically by the Nitro `netlify` preset)
2. Node 22 is pinned via `netlify.toml` / `.nvmrc`.
3. Optional env var: `LOVABLE_API_KEY` enables the AI chat widget. Without it the widget replies with the WhatsApp/email fallback instead of erroring.
4. Logo and hero video are self-hosted in `public/media/`, so all media loads from your own domain after deploy.
